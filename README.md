# わくわく学習アプリ（漢字ドリル ＆ 総合学習プラットフォーム）

## 📖 概要

文部科学省の学習指導要領に準拠した、子どもたちが自発的・楽しく継続して学べる総合学習Webアプリケーションです。  
漢字クイズに正解すると難易度に応じたポイントが貯まり、**「1pt = 1円のお小遣い換金」** や **「為替（米ドル円）連動でおトクに本が買えるバリューブックス連携」** を実現。  
さらに、保護者が安心して任せられる **「4桁PIN認証」** と **「月間1,000pt / 日別50ptの上限管理システム（月末残枠自動解放）」** を備えています。

iPad（Air第2世代等）でのタッチ操作・横画面（ランドスケープ）に完全最適化されており、サーバー不要で `index.html` をブラウザで開くだけで即座に動作します。

## ✨ 主要機能一覧

### 1. 🧭 総合学習ポータル（科目選択メニュー）
- アカウント選択後、3教科の総合メニューを表示：
  - 📚 **国語・漢字ドリル**: 1〜6年生の配当漢字、一文字・熟語・短文クイズ。
  - 🔢 **算数クエスト**: 計算・文章題・九九特訓（開発プラン設計済）。
  - ⌨️ **ローマ字タイピング**: ホームポジション・漢字連動入力（開発プラン設計済）。
- **目標の本プログレスバー**: ウィッシュリストに登録中の本がある場合、ポータルトップに達成率（%）と残り金額を自動表示。

### 2. 📚 漢字ドリル ＆ 苦手克服システム
- **出題バリエーション**:
  - 一文字（低学年でも学びやすい大文字）
  - 二字熟語・四字熟語
  - 短文穴埋め（赤枠ハイライト＋意味ヒント）
- **文字・UIのハイブリッド設計**:
  - 出題漢字・選択肢: **美しい明朝体（Noto Serif JP）**
  - UI・ボタン: **親しみやすい丸ゴシック（M PLUS Rounded 1c）**
- **苦手重点出題**:
  - 間違えた問題を LocalStorage に記録し、次回の出題時に約45%の確率で優先出題。
  - 克服すると「💮 こくふくボーナス (+2pt)」を獲得！
  - 苦手問題だけを集中的に解く「🔥 にがて特訓モード」を完備。

### 3. 🪙 難易度別ポイント ＆ お小遣い・本交換通帳
- **難易度ポイント**:
  - ★1文字: 1pt / ★★熟語: 2pt / ★★★四字熟語・短文: 3pt / 💮苦手克服: +2pt
- **お小遣い換金**: 1pt = 1円として換金・申請可能。
- **バリューブックス為替連動交換**:
  - 公開為替API（USD/JPY）からリアルタイムレートを取得（例: 1ドル = 158.50円）。
  - 100ptを1ドルとして日本円に換算するため、お小遣いよりも**1.5倍以上おトクに本が買える！**
- **📖 ほしい本メモ（ウィッシュリスト）**:
  - バリューブックスの「読みたい本」をメモ（タイトル・価格・URL）。
  - 現在のポイント換算額から「達成率（%）」と「あと何円分」かを自動計算。
  - 「🛒 本を見に行く ↗」で公式商品ページへジャンプ。
  - 「🎉 買ってもらった！」で本ポイントを精算し、通帳に記念ログを記録。

### 4. 🔒 保護者専用4桁PIN認証 ＆ ポイント上限管理
- **4桁PINテンキーモーダル**:
  - 初期暗証番号: **`0000`**
  - 保護者メニュー内から、iPad上でいつでも新しい4桁番号に変更可能。
- **ポイント獲得上限システム**:
  - **月間上限**: 1,000 pt（＝1,000円分）
  - **日別目安**: 50 pt（＝50円分）
  - **月次自動リセット**: 毎月1日0時に月間カウント、毎日0時に日別カウントが自動リセット。
  - **月末残枠解放（キャリーオーバー）**: 月末に月間上限まで余裕がある場合、1日50ptの制限を超えて残枠まで一気に獲得可能。
  - **保護者可変設定**: 月間上限（pt）、1日上限（pt）、残枠解放のON/OFFをiPad上で自由に設定変更可能。
  - **上限到達通知**: 上限到達時は「🌟 今日のポイント上限に達したよ！（練習クイズは続けられるよ）」とお知らせし、子どもの学習を止めません。

### 5. 👥 アカウント管理（最大3人分）
- 生まれた年（西暦）を入力すると、日本の学年度（4月2日〜翌年4月1日）に基づき学年を自動判定。
- アカウントごとにポイント・通帳履歴・ウィッシュリスト・苦手履歴を完全分離保存。

### 6. 📱 iPad横向き（ランドスケープ）最適化
- iPadスタンド設置や外付けキーボード利用を想定し、横幅を活かしたマルチカラムレイアウトとスムーズな操作性を実現。

> [!IMPORTANT]
> ### ✍️ iPadOS スクリブル（Apple Pencil手書き入力）対策の技術的記録【削除・改変禁止】
> iPad Safari / PWA 環境において、Apple Pencil を素早く動かした際に最初のストローク（`pointerdown`）がアプリに届かず描画が取りこぼされる不具合が存在します。本アプリでは `app.js` の `WritingCanvas` 内で以下の回避策を実装しており、**将来のリファクタリング等で絶対に削除・改変してはなりません**：
> 1. **原因**: iPadOS の「スクリブル」機能が素早いペン入力を「テキスト入力欄への手書き文字入力」と誤認して `pointerdown` をブラウザが横取り・破棄してしまう Safari の既知の不具合です。
> 2. **CSS 対策の無効性**: `touch-action: none` や `user-select: none` は既に設定されていましたが、OS 側のスクリブル横取りには効果がありませんでした。
> 3. **必須条件 (`passive: false`)**: 各キャンバスに対して `addEventListener('touchmove', handleTouchMovePrevent, { passive: false })` を登録し、イベントハンドラ内で `e.preventDefault()` を呼ぶことでスクリブルのジェスチャー判定を強制キャンセルしています。`passive: false` でないと `preventDefault()` がブラウザ仕様により無視されます。
> 4. **名前付き関数の必須性**: インライン無名関数で登録すると `removeEventListener` による解除ができず、問題が切り替わるたびに `init()` が呼ばれてリスナーが多重に積み上がってしまうため、必ず名前付き関数 `handleTouchMovePrevent` として定義・登録・解除を行っています。

> [!NOTE]
> ※ iPad PWAキャッシュの即時反映のため、Service Worker の `CACHE_NAME` を都度インクリメントして配布・検証を行っており、バージョン番号は実態に合わせて v35 へ前進・同期しています。（CACHE_NAME は数値を下げると古いキャッシュが復活するため、番号を前進させています）

## 🚀 起動方法

ブラウザ（Safari, Chrome, Edge等）で `index.html` を開くだけで動作します。

## 🔄 リリース・更新手順（重要）

コードを変更して新しいバージョンを配布する際は、端末（特にiPad PWA）に古いファイルがキャッシュされ続けるのを防ぎ、画面表示と実際の版の食い違いを防止するため、**以下の箇所を必ず同時に更新**してください：

1. **`sw.js:1`**: `CACHE_NAME` のバージョン（例: `'wakuwaku-learning-v31'`）をインクリメントする（※番号を下げると古いキャッシュが再利用される恐れがあるため必ず加算）。
2. **`index.html` 末尾**: `<script>` タグのクエリ文字列（例: `?v=20260831_v31`）を同じバージョン文字列に揃える。
3. **`app.js`（先頭定数）**: `APP_VERSION_LABEL`（例: `'🌸 ばーじょん31 🌸'`）を更新する（※`DOMContentLoaded` 時に画面内の全 `.cute-version-badge` へ一括自動反映されます。初回チラつき防止のため `index.html:73, 372` の初期HTML表記も併せて更新）。
4. **バージョン履歴の更新**: `README.md` のバージョン履歴表、`SPEC_AND_KNOWLEDGE.md`、`コンテキスト.md` のバージョン表記を最新版に更新する。
